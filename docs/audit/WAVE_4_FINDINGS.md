### Findings

**KV-AUD-352 | S3 | Confirmed (executed; reinforces S0 001 + P4) | System build/types | L2/L10 | `npx tsc --noEmit` → exit 0** — **The type-check is a *false green* — `tsc --noEmit` passes with 0 errors locally, which masks the S0 build-break and is blindfolded to the runtime defects.** Running the project's own TypeScript: **0 errors**. But that green is misleading on two counts: **(a)** it passes **only because the 3 untracked files exist on this disk** (`001` — `weaponFormulaResolver.ts` + 2 boss tables); a clean CI checkout (`git checkout` → `npm ci` → `expo export`) compiles **without** them and breaks. **(b)** The project's pervasive type-escape-hatches (P4) — `as any` / `as never` / `as unknown as` / `category: string` / `Set<string>` — **suppress the exact errors a type-checker should raise**: the StatusEffect schism (`190`), the `category`/`MonsterCategory` drift (`166`/`043`), the hybrid `physRatio` gate (`312`), the relic `damageType` divergence (`206`/`344`), the `as unknown as` PlayerSnapshot bypass (`218`). So "tsc is clean" is the *literal embodiment* of "it works one way but really doesn't" — the compiler can't see the bugs because the casts blinded it. → `git add` the 3 files + a CI guard (S0); replace the casts with discriminated unions so the compiler surfaces P1/P3 *before* they ship (the highest-leverage structural fix, per `08`). *Verification: executed (`tsc`).* *Pattern: S0 (001) + P4.* 

**KV-AUD-353 | S3 | Confirmed (executed) | System architecture | L1/L3 | `npx madge --circular` → 23 cycles** — **23 circular dependencies — including 3 *runtime* store cycles the inline-`require()` hacks don't hide.** `madge --circular` reports **23** cycles: **(a) 3 runtime store cycles** — `useCharacterStore ↔ useSacredItemStore`, `useCharacterStore ↔ useShopStore`, and a 4-hop `useCharacterStore → useShopStore → consumables → useInventoryStore → (back)`. **KV-AUD-354 | S2 | Confirmed (executed; ★ validates the dead-code inventory + adds orphans) | System dead-code | L3 | `npx knip` (files + exports)** — **knip independently confirms the audit's orphan findings AND surfaces new dead code the per-area reads didn't reach.** With `entry:['app/**']`: **(1) Confirms reading-based findings** — `knip --include exports` flags as unused exactly the functions the audit called dead: `getStatusAppliedNarration`/`getStatusDamageNarration` (**307**), `getMaterialsForMonster`/`rollMaterialDrop` (**340**), `isSuffixAllowedOnFloor` (**309**), `getCarryCapacity` (**159**), `calculateGoldDrop` (**164**), `applySoftCap` (**148**); `knip --include files` flags `pantheons/maya.ts` + `inca.ts` (**347**) and `types/index.ts` (the dead barrel, **217**).
