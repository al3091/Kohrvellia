**KV-AUD-364 | S3 | Confirmed (exhaustive read) | System pantheons/balance | L9 | `pantheons/*` statBonus values** — **Deity `statBonus` is NOT normalized across pantheons — the patron choice has a hidden min-max optimum.** The **older** pantheons (greek/norse/egyptian/japanese/celtic/mesopotamian/hindu/chinese/slavic/aztec) use a uniform **+10 bonus / −5 penalty** (net +5); the **newer** pantheons (persian/shinto/vodou/polynesian/yoruba) use **+12 to +15 bonus / −5 to −7 penalty** — e.g. `Verethragna +15STR/−5INT`, `Inari Ōkami +15LCK/−5END`, `Ahura Mazda +12WIS/−5STR`, `Ogou Feray +12STR/−5WIS`, `Marinette +12STR/−7WIS`, `Bossou +12END/−5AGI`. So a min-maxing build **always** picks a newer-pantheon patron (a +15 primary vs +10) — the deity decision, meant to be a flavorful, roughly-equal patron pick (a "Meaningful Choice" pillar), is **mechanically dominated** by the later-authored pantheons. (Machine refint 351 validated stat *validity*; this is the *value-normalization* the exhaustive read exposes.) → normalize the bonus/penalty budget across all pantheons (or make the variance intentional + documented). *Verification: sim (imported values) + read.* *Pattern: balance asymmetry (P8-adjacent).* 

**KV-AUD-365 | S4 | Confirmed (exhaustive read) | System pantheons/content | L8 | `pantheons/{polynesian,yoruba,vodou,persian,shinto}.ts` + `japanese.ts` (omoikane)** — **Inconsistent `loreSnippet` quoting — ~71 deities carry stray embedded quote marks → they render as `""…"`.** The **5 newer pantheons** (polynesian/yoruba/vodou/persian/shinto, 14 each = 70) **plus** japanese `omoikane` store the `loreSnippet` **with literal `"…"` quote characters inside the string** (e.g. Maui `"\"A great fish approached the hook…\""`, Olodumare `"\"I do not argue. (Includes the `omoikane` `""Think eight thousand…` artifact.) → strip the embedded quotes from the 71 (or add them to all 310, consistently). *Verification: read.* *Pattern: P3 (content-format inconsistency).*
